# HyperKart — 操作手順書

12台、3周、3コース。素材ファイルを持たず、地形も音も実行時に作られる。

---

## 1. 最初の一分

1. **ページを開く。** 操作カードが出て、**グリッドは止まったまま**待つ。カウントダウンは始まらない。
2. **カードを読む。** キー割り当ては実際の設定から生成されているので、書いてあるとおりに効く。
3. **「START RACE」を押す。** ここでレースが始まり、同時に音が鳴り始める。

音が要らなければ、`?` の左のスピーカーを押すか `M`。**設定は記憶される。**

---

## 2. 操作

| キー | 効果 |
|---|---|
| `W` / `↑` | アクセル |
| `S` / `↓` | ブレーキ、そのまま後退 |
| `A` `D` / `←` `→` | ステア |
| `Shift` / `Space` | ホップ、押しっぱなしでドリフト |
| `E` / `Ctrl` | 所持アイテムを使う |
| `C` | 後ろを見る |
| `H` / `?` | 操作カードの開閉 |
| `M` | 音のオン/オフ |
| `Esc` | 操作カードを閉じる |

ゲームパッドも使える。左スティックでステア、右トリガーでアクセル、ショルダーでドリフト。

---

## 3. ドリフト

**コーナーでホップして、押したまま曲がる。** 溜まると三段階に色が変わり、離した瞬間にミニターボが出る。

| 段 | 色 | 溜め | 加速 |
|---|---|---|---|
| 1 | 青 | 1.00 | 0.85 |
| 2 | 橙 | 2.20 | 1.30 |
| 3 | 紫 | 3.80 | 1.90 |

**スティックをドリフト方向へ深く倒すほど速く溜まる。**逆に、まっすぐへ戻し切った状態が続くとドリフトは解除される。

外側へ膨らむのが物理的に正しい挙動なので、コーナーの外に余裕がないラインでは紫まで溜まらない。特に Rainbow Skyway は壁が無く、溜めきろうとすると落ちる。

---

## 4. アイテム

**`?` ボックスを通ると1つ手に入る。**

> **一度に一つだけ。** 枠が埋まっている間、ボックスは開かない。通過してもアイテム枠が横に振れるだけで、それが「もう持っている」の合図である。

取られたボックスは 3 秒で戻る。その間は路面に**暗いパッドだけが残り**、戻りが近づくと明るくなる。パッドがあってボックスが無ければ、それは「誰かが取った直後」である。

| アイテム | |
|---|---|
| バナナ / 三連 | 後方に置く |
| 緑甲羅 / 三連 | まっすぐ飛ぶ。壁で跳ねる |
| 赤甲羅 / 三連 | 前の一台を追う |
| キノコ / 三連 | 短い加速 |
| スター | 無敵と加速。触れた相手を弾く |
| サンダー | 全員を縮ませる |
| 弾丸 | ラインに乗って一気に順位を上げる |

**順位が後ろほど強いものが出る。**先頭はバナナと緑甲羅ばかりで、最下位付近ではスター・サンダー・弾丸が出る。

## 5. 画面

| 位置 | |
|---|---|
| 左上 | 周回 |
| 上中央 | アイテム枠 |
| 右上 | スピーカー、`?`、ミニマップ、前後との差 |
| 左下 | コイン、順位 |
| 右下 | 速度計 |

**ミニマップ**上の点が各カート。自分は強調される。
**前後との差**は、すぐ前とすぐ後ろの相手の名前と秒差。

## 6. コース

| コース | 性格 |
|---|---|
| **Sunset Coast** | 夕方の海沿い。路肩が広く、失敗しても戻れる。最初はここ |
| **Canyon Rush** | 峡谷。登り降りとバンクが強く、平均速度が最も高い |
| **Rainbow Skyway** | 宇宙の虹路。**壁が無い。**外に出れば落ちる。路面が光っており、その光がカートを下から照らす |

各3周。

---

## 7. キャラクター

12人が**軽・中・重**の三クラスに分かれ、**クラスごとに車体が違う**。

| クラス | 車体 | 見え方 |
|---|---|---|
| 軽 | `dart` | 細くて長い。小径タイヤ |
| 中 | `gt` | 標準 |
| 重 | `bruiser` | 幅広で、ほぼ正方形。大径タイヤ |

重いほど最高速と押し負けにくさ、軽いほど加速と旋回。

## 8. URL パラメータ

| 指定 | 効果 |
|---|---|
| `?track=sunsetCoast\|canyonRush\|rainbowSkyway` | コース |
| `?character=nova\|blitz\|boulder\|…` | 自機 |
| `?quality=low\|medium\|high\|ultra` | 画質 |
| `?field=2..12` | 台数 |
| `?seed=数値` | レースの乱数種 |
| `?cam=chase\|near\|far\|bumper` | カメラ |
| `?mute=1` | 無音で開く |
| `?auto=1` | AI が自機を運転（アトラクト） |
| `?laps=1..9` | 周回数。既定は 3 |
| `?shot=1` | 撮影モード。ループを止め、時計を `window.__hk` に渡す |

例：

```
http://localhost:5178/?track=rainbowSkyway&character=boulder&cam=bumper
http://localhost:5178/?track=canyonRush&mute=1&quality=ultra
```

## 9. 動画を撮る

運転が下手でも構わない。**AI に走らせて録画する**方法が二つある。

### 音がいらないなら — オフライン書き出し（きれい）

```bash
node tools/movie.mjs --track canyonRush --laps 1
node tools/movie.mjs --track sunsetCoast --w 3840 --h 2160     # 4K
node tools/movie.mjs --seconds 20 --cam bumper --hud 0         # 車載20秒
```

1フレームずつ書き出すので、**PC の速度に関係なく完璧な 60fps** になる。カクつきは原理的に起きず、4K でも画質が落ちない（時間がかかるだけ）。

**AI の周回タイムは人間よりだいぶ遅い**ので、想像より長い動画になる。実測：

| コース | 1周 | 3周ゴールまで |
|---|---|---|
| Sunset Coast | 約63秒 | 190秒 |
| Canyon Rush | 約67秒 | 200秒 |
| Rainbow Skyway | 約73秒 | 220秒 |

書き出しは 1080p で 1フレーム約 85ms。**1周ぶん（映像79秒）で7分、3周ぶんで20分**ほどかかる。短いクリップが欲しいときは `--laps 1` ではなく **`--seconds 20`** のほうが速い。

| 指定 | 既定 | 意味 |
|---|---|---|
| `--track` | `sunsetCoast` | コース |
| `--laps` | 3 | 周回数 |
| `--seconds` | — | 秒数で打ち切る。指定しなければゴールまで |
| `--w` `--h` `--fps` | 1920 1080 60 | 解像度とフレームレート |
| `--cam` | `chase` | `chase` `near` `far` `bumper` |
| `--hud 0` | 表示 | HUD を消す |
| `--out` | `movie/<コース>.mp4` | 出力先 |
| `--crf` | 20 | 小さいほど高画質・大容量。20 で 1080p60 が約 21Mbps |
| `--preset` | `medium` | x264 の圧縮の粘り。`slow` は時間対効果が薄い |
| `--png` | JPEG | 連番を可逆で出す（重い） |

**容量は大きい。**1080p60 は動きが激しいので、79秒で約 200MB になる。共有用に軽くするなら `--crf 23`（半分弱）。

**ffmpeg があれば mp4 まで作る。**無ければ連番画像を残し、結合するコマンドを表示する（`brew install ffmpeg`）。

### 音が要るなら — 画面収録

```
http://localhost:5178/?auto=1&track=canyonRush
```

を開いて `Cmd + Shift + 5`。AI が勝手に走るので操作は不要。**音がそのまま入る**代わりに、フレームレートは PC の実力なりになる。

---

## 10. 重ければ

右上の画質は URL 指定だが、**解像度は自動で調整される**（60fps を保つために内部解像度を落とす）。それでも重い場合は `?quality=medium` か `low`、あるいは `?field=6` で台数を減らす。

---

## 11. 動かす

```bash
npm install
npm run dev            # http://localhost:5178  開発用
npm run build          # dist/ 静的サーバに置く用
npm run build:single   # dist/hyperkart.html  1ファイル、ダブルクリックで開く
```

**`index.html` を直接ブラウザで開いても動かない。** `<script type="module">` は `file://` から読み込めないというブラウザ側の規則による（プロジェクトの不具合ではない）。サーバ無しで動かしたい場合は `build:single` を使う。

| やりたいこと | コマンド | 結果 |
|---|---|---|
| 開発する | `npm run dev` | vite、ホットリロード |
| どこかに置く | `npm run build` | `dist/` を静的ホスティングへ。相対パスなのでサブディレクトリ可 |
| 人に渡す | `npm run build:single` | `dist/hyperkart.html` 1枚。USB でもメール添付でも動く |

技術詳細と開発回顧は `docs/TECHNICAL.md`。
